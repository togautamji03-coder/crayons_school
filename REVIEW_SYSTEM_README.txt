PARENT REVIEW SYSTEM
====================

Public review page:
    review.php

Public submissions are stored in:
    reviews.json

Default workflow:
    Parent submits -> Pending -> Admin approves/rejects -> Approved review is published

Admin dashboard:
    admin.php -> Parent Reviews

Approved reviews are synchronized to:
    index.html
    testimonial.html

Optional parent photo uploads are stored in:
    img/review_*.jpg/png/webp

No database is used.
